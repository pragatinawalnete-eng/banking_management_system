# 🏦 Banking Management System

A Java-based Banking Management System developed using Object-Oriented Programming (OOP) concepts.

Currently, the project implements **Module 1: Customer & Account Management** and **Module 2: Banking Transactions**.

---

## 📌 Project Overview

The Banking Management System is designed to manage basic banking operations such as customer registration, account creation, deposits, withdrawals, money transfers, balance checking, and transaction history.

The project is developed in **Java** and demonstrates important OOP concepts including classes, objects, constructors, encapsulation, object relationships, and ArrayList.

---

## 🎯 Objectives

- Manage customer information
- Create and manage bank accounts
- Perform banking transactions
- Maintain transaction records
- Check account balances
- Demonstrate Java OOP concepts

---

## 📚 Modules Implemented

### Module 1 – Customer & Account Management

This module manages customers and their bank accounts.

**Classes:**
- `Customer`
- `Account`
- `Bank`

**Features:**
- Register customer
- Create account
- View customer details
- Update customer information
- Display account details
- Manage account balance

---

### Module 2 – Banking Transactions

This module handles banking transactions.

**Classes:**
- `Transaction`
- `TransactionManager`

**Features:**
- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- Store transaction records
- Display transaction history

---

## 🧠 OOP Concepts Used

- **Class & Object**
- **Encapsulation**
- **Default Constructor**
- **Parameterized Constructor**
- **Copy Constructor**
- **Getters and Setters**
- **Object Relationship**
- **ArrayList**
